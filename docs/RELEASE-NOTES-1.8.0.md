# Hunter's Bestiary 1.8.0 — Release Notes

Hunter's Bestiary 1.8.0 turns Fieldwork into a configurable staged investigation. Rumors gate Tracks, successful Tracks can unlock Sightings, Sightings can reveal absolute danger, and the player can then decide to defer the quarry or submit a GM-approved Hunt proposal.

The release keeps intended Hunt outcome separate from actual adjudicated outcome, preserves existing progress compatibility, and optimizes the potentially large Hunt monster selector with lazy bounded rendering.

See `HUNT-SYSTEM.md`, `GM-GUIDE.md`, `PLAYER-GUIDE.md`, and `TEST-PLAN.md`.
