# Hunter's Bestiary 1.7.0 — Hunt System Redesign

This feature release makes a hunt a coherent progression from uncertain rumor to identified quarry, research, pursuit and player-chosen final objective.

## Highlights

- configurable global and per-monster minimum knowledge required to start hunts;
- configurable rumor quarry pool with completed-quarry repeat avoidance;
- anonymous first-contact Bestiary entries;
- per-field disclosure thresholds for level, points, successful rumors and chance;
- optional GM approval for sensitive discoveries;
- conservative default name and weakness discovery;
- no preselected outcome at Hunt creation;
- player-selected desired outcome during Resolve the Hunt;
- configurable automatic, check-plus-GM and GM-only resolution policies;
- actual GM-adjudicated outcome may differ from the player's intention;
- escaped quarry remains active for re-hunting;
- legacy visibility compatibility for existing campaigns;
- optimized Hunt Rules lists and per-monster override workflow.
