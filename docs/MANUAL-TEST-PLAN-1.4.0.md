# Manual Runtime Acceptance — 1.4.0

## Installed-world image selection

1. Enter the world as a GM.
2. Open the relevant dashboard.
3. Click an existing monster or species image.
4. Select an existing image through Foundry's image FilePicker or use its upload control when permitted.
5. Confirm the dashboard image changes.
6. Confirm the linked Actor portrait changes.
7. Open the Actor prototype-token configuration and confirm the texture source matches.
8. Update or re-import the managed Actor and confirm the selected override remains.

## Reset and permissions

1. Use **Restore packaged image** and confirm only the override is removed.
2. Confirm the uploaded file itself is not deleted.
3. Confirm a non-GM cannot open the image picker or change an override.
4. Confirm undiscovered player entries retain the generic concealed image.
