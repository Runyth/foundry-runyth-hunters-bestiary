# Runyth Hunter's Bestiary 1.3.1 Release Notes

Released 2026-07-31. Patch release from 1.3.0.

## Fixed

- Bestiary list-card subtitles such as `Tier 5 · Unknown` now receive independent line height, wrapping space, and content-driven card height.
- Record Sighting and Record Trophy or Sample now open as resizable ApplicationV2 windows.
- Each record type stores client-specific position and dimensions through the existing geometry store.
- Record-form inputs and textareas now use border-box sizing and balanced right-side padding.

## Compatibility

Stable module IDs, settings, managed content, knowledge progression, and public APIs are unchanged. No migration action beyond replacing the module folder is required.
